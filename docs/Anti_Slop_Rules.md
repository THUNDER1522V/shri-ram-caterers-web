# Anti-Slop Rules

## Never

- Use AI-generated food images
- Use stock wedding photos
- Use fake testimonials
- Use generic hero text
- Use more than two font families
- Use random gradients
- Use unnecessary animations
- Use inconsistent spacing
- Use multiple button styles
- Use autoplay music
- Overuse gold accents
- Use flashy transitions
- Sacrifice performance for visual effects

---

## Always

- Use real event photography
- Use original videos
- Keep generous whitespace
- Maintain consistent spacing
- Use editorial typography
- Prioritize mobile experience
- Optimize loading speed
- Use animations with purpose
- Tell authentic stories
- Build trust before selling
Every feature must satisfy at least one of:

Improves Trust

Improves Performance

Improves Accessibility

Improves SEO

Improves Conversion

Improves Maintainability
