# Shri Ram Caterers – Brand System

## Vision

To build one of India's most premium catering websites that feels luxurious, trustworthy, cinematic, and timeless.

The website should not look AI-generated. Every design decision must be intentional and based on the brand system documented in this repository.

---

## Project Goals

- Build trust within the first 5 seconds
- Showcase real events and real food
- Create a luxury wedding experience
- Mobile-first design
- Fast loading
- High accessibility
- Premium animations
- Consistent design system

---

## Brand Personality

- Elegant
- Trustworthy
- Warm
- Timeless
- Premium

---

## Design Philosophy

Less, but better.

Every animation, every image, every word and every interaction should have a purpose.
